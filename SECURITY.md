## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.
Please report vulnerabilities privately via email or GitHub Security Advisories.
Do not create public issues for security vulnerabilities.

1. Email us with details about the vulnerability.
2. We will acknowledge receipt of your vulnerability report within 48 hours.
3. We will try to send you a regular update about our progress.
4. If you have not received a reply to your email within 48 hours, or have not heard from us for a week, please reach out again.

## Security Practices Followed

- Input validation
- CORS and basic Security Headers
- Secrets management via environment variables
- Automated dependency updates
- SAST scanning
