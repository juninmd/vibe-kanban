# Roadmap: Vibe Kanban 3D (The Future)

This roadmap outlines the evolution of Vibe Kanban from a static prototype to a fully autonomous, visually immersive operations center.

## Phase 1: The "Alive" Update (Current Focus)
**Goal:** Make the system feel alive and responsive without constant user intervention.

- [x] **Auto-Pilot Mode:** The "Product Manager" agent autonomously assigns tasks from the backlog to idle agents based on their specialization.
- [x] **Visual Celebration:** When a task is completed, the 3D environment reacts (Confetti/Particles).
- [x] **Real-time Updates:** Switch from polling to Server-Sent Events (SSE) for instant feedback.

## Phase 2: Visual Fidelity & "Juice"
**Goal:** Enhance the aesthetic to be worthy of a sci-fi operations room.

- [ ] **Agent Personalities:** Unique visual trails or colors for different agent roles (e.g., Security = Red Shield, Performance = Blue Lightning).
- [ ] **Interactive 3D:** Click to drag tasks in 3D space.
- [ ] **Dynamic Lighting:** Lights that dim when the system is idle and brighten when activity peaks.

## Phase 3: Deep Intelligence
**Goal:** Give agents real agency and reasoning capabilities.

- [ ] **Contextual Memory:** Agents remember past bugs and use that knowledge to prevent future ones.
- [ ] **Inter-Agent Chat:** Agents "talk" to each other (visualized as chat bubbles) to resolve dependencies.
- [ ] **Code Execution:** Agents can actually run code snippets in a sandboxed environment (using OpenCode/Codex).

## Phase 4: Scale & Persistence
**Goal:** Production-ready reliability.

- [ ] **Database Persistence:** SQLite/PostgreSQL storage.
- [ ] **Multi-Room Support:** Different rooms for different projects/teams.
- [ ] **External Integrations:** GitHub/Linear sync.

---

*Surprise Execution Note:* The "Auto-Pilot" and "Visual Celebration" features are being deployed immediately to demonstrate the potential of an autonomous system.
